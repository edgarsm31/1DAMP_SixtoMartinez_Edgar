
## ¿Qué es un programa informático?

Un programa informático es un conjunto de instrucciones escritas en un lenguaje de programación que indican a un ordenador qué tareas debe realizar. Estas instrucciones permiten resolver problemas, procesar datos y realizar diferentes operaciones de forma automática.

Los programas pueden ser muy sencillos, como una calculadora, o muy complejos, como un sistema operativo o una aplicación web.

## Diferencia entre código fuente, código objeto y código ejecutable

### Código fuente

El código fuente es el conjunto de instrucciones que escribe un programador utilizando un lenguaje de programación, como Python, Java, C++ o JavaScript.

Es legible y modificable por las personas y contiene la lógica necesaria para que el programa realice sus funciones.

### Código objeto

El código objeto es el resultado de traducir el código fuente mediante un compilador. Está formado por instrucciones en un formato intermedio que el ordenador puede procesar, aunque normalmente todavía necesita otros pasos para convertirse en un programa ejecutable.

Por ejemplo, en lenguajes compilados como C o C++, el compilador puede generar archivos de código objeto antes de crear el ejecutable final.

### Código ejecutable

El código ejecutable es el resultado final que puede ser ejecutado por el sistema operativo para poner en funcionamiento el programa.

Normalmente contiene el código necesario, junto con otros componentes, para que el ordenador pueda ejecutar las instrucciones del programa.

## Etapas del desarrollo de software

Este ciclo se puede dividir en siete fases:

1. **Planificación:** se establecen los objetivos, el alcance y los requisitos generales del proyecto.

2. **Análisis:** se recopila y analiza la información necesaria para determinar los requisitos del software.

3. **Diseño:** se define la arquitectura del software, su estructura, las interfaces y otros elementos necesarios para su funcionamiento.

4. **Codificación:** los programadores escriben el código y construyen el software basándose en el diseño y los requisitos establecidos.

5. **Pruebas:** se comprueba el funcionamiento del software para detectar y corregir errores y comprobar que cumple los requisitos.

6. **Implementación:** el software se instala en el entorno de producción y se pone a disposición de los usuarios.

7. **Mantenimiento:** después de su implementación, se realizan correcciones, actualizaciones y mejoras del software.
